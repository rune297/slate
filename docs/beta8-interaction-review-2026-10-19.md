# Slate 1.5.0-beta.8 交互修复验收

本次修复两项问题：有时点击工作台外无法收起；向下过拽时顶部露出桌面空隙。仅生成本地 Windows 安装包，未上传 GitHub，未操作正式用户数据。

## 外点无法收起

排查发现不止一个原因：

- 显式外点原本沿用了光标离开时的 16px 防抖区域，边缘外点击可能被当作内部。
- 拖动和回弹期间直接丢弃退出请求；原窗口失焦后不会再来一次失焦事件。
- Windows 下不允许激活的 Chromium 透明感应窗可能在原生消息层吞掉按压。真实测试确认鼠标命中的是本测试感应窗，前台仍是主面板，页面却没有收到 mousedown；合成页面点击无法发现这条路径。

最终方案保持感应窗不抢焦点，观察其自身 HWND 的 WM_MOUSEACTIVATE，在 DOM 吞按压之前复用外点判断。只监听这个窗口，没有增加全局鼠标钩子。Windows 命中层使用最低非零透明度，避免完全透明像素跳过命中；收起感应时恢复完全透明和穿透。

判断统一使用 Windows DIP 与真实窗口边界；动画和回弹期间保留退出意图，交接后执行。展开时覆盖显示器并集；固定、系统文件/权限对话框和 Slate 子窗口操作期间暂停捕获。离线模型导入也纳入对话框保护。

首次外点的职责是关闭工作台。没有向其他应用重放鼠标点击。

## 下拽顶部空隙

保留整个工作台的位移、阻尼和释放回弹，背景向上延伸 32px，覆盖阻尼上限内的全部顶部区域。标题栏与卡片仍一起移动，不裁切内容模拟手势，不逐帧修改原生窗口尺寸。

真实鼠标检查了两种主题下的过拽、顶部覆盖和像素不透明度；释放后恢复普通背景范围，动画对象释放。

## 触发方式评估

悬停和主动下拉适合作为快捷工作台的两个独立入口，不应要求先悬停再拖动。当前保留顶部约 0.5 秒驻留、直接按住细条下拉、点击和快捷键。

应继续遵循：短暂停留避免路过即开；主动拖动及时跟手；短拉回弹、超过阈值释放展开；非固定工作台可靠外点收起，Esc 逐层退出。固定模式是明确例外。

这是针对 Slate 的产品判断，并非所有桌面软件都采用悬停与下拉组合。微软的[轻量浮层规范](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/dialogs-and-flyouts/flyouts#light-dismiss-behavior)支持外点和 Esc 退出；默认首次外点也可能由浮层吸收。原有“未获焦点时移开可延迟收起”的兜底，以及拖动其他窗口经过顶部时的防误触，仍可作为后续交互简化项；本次没有另增唤出设置或改变驻留阈值。
