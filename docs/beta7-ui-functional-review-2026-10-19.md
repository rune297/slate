# Slate 1.5.0-beta.7 界面与功能验收

本次针对按钮遮挡、开关状态、AI 配置三个反馈修改源码并生成本地 Windows 安装包。没有发布 GitHub，也没有在正式用户目录导入示例、改配置或覆盖记录。

## 已处理的问题

| 问题 | 修改后的行为 | 验证方式 |
| --- | --- | --- |
| 首页优化器底部按钮被裁切 | 编辑区按需滚动，优化、复制、存为片段固定保留在卡片内；补充要求展开同样适用 | 6 种尺寸 × 双主题，检查按钮上中下三个位置的真实命中及卡片底部留白 |
| 深灰开关只有位置区别 | 开启使用浅石色轨道和深滑块，关闭使用深轨道和浅滑块；浅色保持深轨道表示开启 | 16 个开关组件 × 双主题，开启/关闭轨道对比、开启滑块对比均 ≥3:1 |
| 无服务仍展示只有“不使用 AI”的列表 | 无服务时展示添加入口与下一步说明；保存后再分配各用途 | 全新隔离配置，真实点击添加、保存服务、保存分配 |
| 关键模型输入和后续设置不明显 | 模型输入与读取按钮同排；保留可手填；高级地址默认收起；未显示完时提示向下滚动 | 标准/矮窗口截图及输入、提交按钮可点击检查；700×480 四项功能可见 |
| 模型失败原因全是一句话 | 未填 Key 时不发送请求并聚焦输入；区分 401、403、404/405/501、429、5xx、空列表、无效响应、DNS、网络、证书、超时与取消 | 单元和 Electron 错误响应测试；读取不写配置，成功/失败均保留手填模型 |
| AI 网络请求没有沿用桌面代理 | 模型读取、连接测试、优化、报告、整理和录音后转写使用 Electron 网络栈 | 真实本地 HTTP 代理验证读取/生成/测试请求，检查不附带 Cookie、不跟随重定向、可取消 |

这里没有将每次获取失败都归因于代理或 Key。旧代码会将多种原因吞成相同提示，因此不能仅凭原截图确定实际服务器错误。服务商本身也可能不提供模型列表接口，手填模型后测试连接仍可使用。

## 本轮检查范围

- 254 项单元测试通过，48 个运行时文件语法检查通过。
- 26 组桌面交互检查完成，覆盖焦点/点击外部收起、真实鼠标双向手势、快捷键、任务与图片附件、笔记自动保存与撤销、剪贴板检索与批量操作、录音、报告草稿/历史、设置、AI 配置与复制反馈。
- 全量流程在真实鼠标手势测试中发生一次时序超时；保留原失败日志，隔离复核通过。其余未完成组随后继续运行，不把最初的整条测试命令标成一次全绿。
- 页面检查覆盖首页、服务配置、功能分配、首页开关、报告、待办、笔记、剪贴板、链接、录音资料库、保密箱，以及全部九类设置导航。两种主题，1100/700 两档宽度，650/560/480 三档高度，共 132 个页面状态；批量截图并抽查关键页面。
- 录音资料库和保密箱仅在隔离验收配置中主动开启，未改变新用户默认功能。
- 打包程序完成全新启动、同一测试数据重启、复制 beta.6 隔离数据后升级三轮验证；包含加密凭据、工作记录、录音、模型读取、提示词/报告独立模型和原生复制提示。

本轮范围内没有留下已复现但未处理的阻塞性产品问题。截图和自动化不能证明所有数据、屏幕缩放、真实服务商和硬件组合都没有问题。

## 验证边界

- 未使用用户真实 Key 逐一调用 19 个服务商。真实请求使用独立本地模型接口与 HTTP 代理；云端鉴权、错误和协议由受控响应验证。真实账户的地域、额度、模型权限仍以服务商响应为准。
- 录音测试使用测试音频/虚拟设备；未重新做真实麦克风长录音或人工检查转写质量。
- 未执行安装器完成系统安装或卸载；已测试安装包内对应的实际打包程序。
- 没有重新做多显示器实机验收或全新电脑验收。

证据文件位于 `dist.noindex/beta7-regression.log`、`beta7-remainder.log`、`beta7-final-ui.log`、`beta7-syntax.log`、`beta7-qa/` 和 `windows-smoke/beta7-package-validation.json`；这些测试产物不进入源码包。

## 接口依据

[Electron 官方 net 文档](https://www.electronjs.org/docs/latest/api/net)说明其 Chromium 网络栈支持系统代理配置，区别于 Node 网络实现。本次使用该网络栈并显式省略 Cookie，未放宽证书校验。[硅基流动模型列表文档](https://api-docs.siliconflow.cn/docs/api/models-get)要求使用当前账户的 Bearer Key；缺少 Key 不能获得受鉴权的模型列表。
