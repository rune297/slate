# Slate 1.5.0

Windows x64 正式版。本次更新相对上一公开版本 **1.4.0-beta.8**，集中完善待办、报告、AI 工具与桌面交互。

## 下载与升级

下载本页附件 `slate-1.5.0-windows-x64-setup.exe`，退出旧版 Slate 后运行安装程序覆盖安装，原有本地数据保留。建议先在「设置 → 数据与备份」导出工作数据；API Key 不在备份内。`SHA256SUMS.txt` 提供安装包校验值。

## 新增功能

- **待办到点提醒**：支持截止、跟进和逾期提醒，默认到点提醒、每日 18:00 汇总未完成事项；可在设置中关闭或改汇总时间，保留已有自定义提醒。右下角紧凑提醒窗可标记完成、延期、打开任务调整或确认「知道了」。收起后顶部保留小型提示条，逾期任务以温和暖色提示。
- **重复事项**：每天、每周指定星期、每月指定日期或指定某一天生成待办；支持结束日期、暂停、恢复和删除规则，已生成的任务独立保留。
- **图片待办与图片笔记**：任务详情、首页随手笔记和笔记库支持选择、粘贴、拖入图片，点击缩略图放大；支持移除，笔记图片移除可撤销，每条最多 8 张、单张不超过 10 MB。剪贴板图片可转成待办，任务和笔记图片纳入工作数据备份。
- **日报、周报、月报**：三个周期使用不同的纯文本模板，可分周期自定义排版与 AI 写作要求。既可无需 API「仅整理任务」，也可主动用 AI 生成；月报包含已完成、未完成与遗留、真实记录的问题与所需协助、下月安排。结果先进入可编辑草稿，主动保存才加入历史；历史支持搜索、多选、图标删除、清空确认和撤销。
- **首页提示词优化**：与本地翻译共用卡片，支持输入或读取剪贴板、补充要求、优化、编辑、复制与存为常用片段。失败、取消和过期响应保留原文；生成中人工修改后，由用户决定是否使用候选结果。
- **复制成功反馈**：桌面左下角显示复制内容概述或文件名，短时间连续复制切换为「去粘贴吧 ×N」，勾选和数字带轻量动效；自动淡出、不抢焦点，可在剪贴板设置关闭，尊重系统减少动画设置。

## AI 与常用工具

- **统一 AI 服务与功能分配**：提供 19 项云端、本地及兼容接口模板，预填地址；服务保存一次 Key，提示词优化、工作报告、智能整理与命名、录音转写各自选择服务和模型，可共享也可分开。支持读取模型、手动填写、连接测试和取消；无服务时明确引导添加。
- 支持 OpenAI 兼容文字接口和 Claude 原生 Messages；支持用户自行运行的 Ollama、LM Studio，本地服务通常无需 Key。模型读取失败会区分鉴权、权限、限流、接口不支持、网络及证书等原因；AI HTTP 请求使用支持系统代理的 Electron 网络栈。
- 原有配置迁移到统一服务列表；Key 使用 Windows 系统安全存储加密，不进入 Git 或工作数据备份。修改服务地址或厂商需重新输入 Key。
- **更多录音转写选择**：保留百炼实时转写，增加兼容 `/audio/transcriptions` 的录音后文件转写，单次最多 10 分钟。先保存音频再转写，失败保留本地录音。
- **常用片段**：入口移到顶部，搜索与新增/编辑分开，支持多行查看、展开全文、直接复制及 Ctrl+Enter 保存，保留旧片段；不会执行片段里的命令。
- **分类与模型管理**：任务分类改为搜索直选；新用户内置「全部分类/未分组」，自定义分类可排序、重命名和删除。离线翻译设置可查看状态、下载、导入、刷新和释放模型内存。

## 交互与修复

- 整个工作台跟随上下拖动，保留边界阻尼、阈值切换和释放回弹；展开后整个底部均可上推收起。
- 修复有时首次点击工作台外部无法收起，以及向下过拽时顶部露出桌面空隙。
- 设置改为左侧分类与搜索、右侧对应内容；统一深浅主题的开关状态、字号、按钮、对齐和间距。
- 修复首页提示词工具底部操作按钮被遮挡、剪贴板收藏与删除图标重叠、报告配置入口不明显等问题。
- 未配置 API、生成异常或取消时不创建报告历史，也不覆盖人工草稿；整理文字不再每点一次就生成新文件。
- 保留未保存的编辑与输入焦点；提醒按最近节点调度、跳过无变化的同步，复制提示采用原生剪贴板事件，窗口和预览资源按需释放。

## 使用边界与验证

- 提醒需要 Slate 在托盘运行；退出、关机及休眠期间不弹窗，启动或唤醒后重新检查。重复事项断档时每条规则只补最近一次，暂停期间不会批量补任务；当月无指定日期时在月末生成。
- AI 报告由用户主动生成，不会后台定时生成。报告仅发送对应任务文字，不发送图片或其他笔记；Skill 导入仅作为写作要求，不执行文件中的命令。
- AI 优化与 AI 报告需自行配置云端 API 或本地模型服务，Slate 不附送额度或生成模型。19 项是配置模板数，不代表所有厂商模型均已实测；费用与兼容性以服务商为准，连接测试也可能产生少量费用。本地翻译仍使用已有离线模型。
- 发行平台为 Windows x64，当前没有自动更新。多显示器混合缩放硬件及真实第三方 API Key 未逐一实测。
- 正式安装包与发布源码均移除示例数据生成与演示账号入口，不会自动添加测试内容。开发回归使用独立测试目录，与用户工作数据分开。
- 验证覆盖单元、桌面交互和运行时脚本语法检查；预览版完成完整功能回归。正式版额外移除示例功能后重新检查，当前桌面整套重跑受鼠标/焦点变化影响，未完整结束。
- 正式包额外检查源码一致性、新建/保留/旧预览版隔离数据升级、真实 Windows 外部点击、加密配置及 AI 模型与用途路由。AI 自动化使用本地测试服务；测试运行正式包内的应用，未在当前机器执行安装向导。
