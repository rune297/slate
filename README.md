# Slate

**从屏幕顶部下拉即用的 Windows 桌面工作台。**

看待办、记笔记、处理剪贴板、翻译文字、整理报告，让日常工作随手可做。

[下载 Windows 版本](https://github.com/rune297/slate/releases/latest) · [功能](#功能) · [快速上手](#快速上手) · [本地开发](#本地开发) · [更新日志](CHANGELOG.md)

</div>

Slate 把待办、笔记、剪贴板、录音和常用工具放进屏幕顶部的面板。平时收起为一条细小的提示条，需要时下拉或用快捷键唤出，用完收回。

首页直接显示今天的事项和完成进度，也可以随手记录文字或图片、优化提示词、离线翻译和打开常用软件。工作数据保存在本机，无需注册账户；AI 服务按需配置。

## 功能

### 待办与提醒

- 按「今天、本周、以后」安排工作，在首页查看任务清单、完成数量和进度。
- 随手添加、勾选完成，临时急事可设为「优先做」，排到首页今天最前面。
- 分别设置计划日期、截止时间和跟进提醒，记录说明、等待反馈、持续跟进与工作卡点。
- 任务支持分类和图片附件，分类可搜索、排序和管理，图片可粘贴、拖入并放大查看。
- 每天、每周、每月或指定日期生成重复事项，支持结束日期、暂停和恢复。
- 到点弹出紧凑提醒，可标记完成、延期、查看任务或确认收到；默认每天 18:00 汇总未完成事项，时间和开关可调整。
- 收起后的顶部提示条以温和暖色提示逾期事项。

### 随手笔记

- 首页直接输入并自动保存，点击「新一条」继续记录。
- 在笔记库中独立新建、搜索和编辑，首页组件隐藏后也能使用。
- 支持文字和图片，也可只记图片；图片可选择、粘贴、拖入、放大，移除后可撤销。
- 待办和笔记每条最多添加 8 张图片，单张不超过 10 MB。

### 剪贴板与文字处理

- 保存文字和图片历史，支持搜索、收藏、暂停采集、保留期限和忽略指定应用。**历史采集默认关闭。**
- 复制文字后按 `Ctrl+Alt+Q`，在任意应用中呼出文字小窗，译为中文、存笔记或转为待办。
- 转待办时将完整原文保留在详情中；单次文字处理最多 6000 字符，超长内容会提示分段。
- 桌面左下角显示复制成功反馈，连续复制显示「去粘贴吧」和累计次数，自动淡出；可在设置中关闭。
- 常用回复、模板和命令可保存为多行片段，搜索后直接复制全文；支持独立编辑和 `Ctrl+Enter` 保存，片段中的命令不会执行。

### 离线翻译与提示词优化

- 首页一键读取剪贴板并翻译为中文，支持自动识别或手动选择源语言、复制译文。
- 翻译使用本地模型，首次下载或导入后可离线运行，翻译原文和译文不上传。
- 提示词优化支持输入或读取剪贴板、补充要求、编辑结果、复制和存为常用片段。
- 优化器只改写提示词，不执行原文任务；失败、取消或生成期间的人工编辑不会被旧响应覆盖。

### 日报、周报与月报

- 按所选时间范围整理待办，展示已完成、未完成、顺延与遗留及事项数量。
- 日报、周报、月报分别使用纯文本模板，月报可整理已记录的问题与所需协助。
- 无需 API 即可「仅整理任务」，也可调用配置的 AI 服务生成草稿。
- 结果可手动修改和复制，草稿保存在本机，主动保存后加入历史。
- 历史支持搜索、多选删除、清空确认和撤销；排版模板与 AI 写作要求可按周期自定义。

### 录音与转写

- 顶部控件直接开始、暂停、继续和停止录音，音频保存在本机。
- 在录音资料库查看音频和转写；保存失败可重试，转写失败仍保留已保存的音频。
- 可选接入百炼实时转写，或使用兼容 `/audio/transcriptions` 的录音后文件转写服务，文件转写单次最多 10 分钟。

### 常用工具与搜索

| 工具 | 可以做什么 |
| --- | --- |
| 快速启动 | 添加常用应用，一键打开或切换到已运行窗口。 |
| 链接收藏 | 保存网址、获取标题和站点图标，按分组管理。 |
| 全局搜索 | 在 Slate 内按 `Ctrl+K`，搜索待办、笔记、链接、剪贴板、片段、录音转写和启动器应用；回车启动应用或复制内容。 |
| 本机密钥 | 可选启用的账号密码管理，支持加密保存、搜索、编辑和分别复制账号与密码。 |
| 任务完成通知 | 接收 Codex / Claude 的任务完成通知，需配置仓库提供的通知脚本。 |

### 工作台与个性化

- 整块面板跟随下拉、上推，支持阻尼、阈值切换和回弹；展开后整个底部都可上推收起。
- 支持快捷键唤出、点击外部收起、固定面板和系统托盘操作。
- 首页默认展示今日待办、随手笔记、提示词优化 / 本地翻译、快速启动四张卡，可调整显隐、位置和大小。
- 支持浅色、深灰和跟随系统主题；设置提供分类导航与搜索。

## 安装

1. 在 [Releases](https://github.com/rune297/slate/releases/latest) 下载 `slate-*-windows-x64-setup.exe`。
2. 运行安装程序，选择安装位置。
3. 启动后，Slate 会常驻系统托盘，屏幕顶部显示细小的提示条。

目前提供 **Windows x64** 安装包。升级时先退出旧版，再运行新版安装程序覆盖安装；建议提前导出工作数据备份。当前采用手动升级。

## 快速上手

| 操作 | 使用方式 |
| --- | --- |
| 展开工作台 | 下拉屏幕顶部细条，或按 `Ctrl+Alt+S`。 |
| 收起工作台 | 从面板底部上推、点击外部，或按 `Esc`。 |
| 连续编辑 | 点击顶部固定按钮，让工作台保持展开。 |
| 记一件事 | 在首页待办输入框输入，回车添加。 |
| 随手记录 | 在首页笔记框直接输入，自动保存；也可粘贴图片。 |
| 快速处理文字 | 复制后按 `Ctrl+Alt+Q`，选择翻译、笔记或待办。 |
| 搜索已有内容 | 在 Slate 内按 `Ctrl+K`，输入关键词。 |
| 生成工作报告 | 进入「待办 → 工作报告」，选择周期与日期，再整理或生成草稿。 |

面板唤出、文字处理、翻译和剪贴板等快捷键可在设置中配置。部分可选功能默认隐藏，可在「设置 → 首页与功能」开启。

提醒和全局快捷操作需要 Slate 在托盘运行。退出或关机时无法提醒；休眠后唤醒会重新检查。重复任务在重新运行时，每条规则只补最近一次，不会批量补齐暂停期间的任务。

## AI 与本地模型

日常待办、笔记、录音和本地报告整理无需配置 AI。需要生成或转写时，在「设置 → AI 配置」添加服务，再为提示词优化、工作报告、智能整理或录音转写分别选择服务和模型。

- 提供 OpenAI、Claude、Gemini、DeepSeek、Kimi、百炼、硅基流动、OpenRouter 等服务模板，支持获取模型、手动填写和连接测试。
- 同一个服务可供多个功能复用，各功能也可选择不同服务和模型。
- 支持自行运行的 Ollama / LM Studio 及兼容接口；本地生成模型由用户自行安装和启动。
- 云端 API 的权限、兼容性和费用以服务商为准，连接测试也可能产生少量费用。录音转写需选择支持音频的模型。

离线翻译使用 M2M100 量化模型，首次在「设置 → 本地翻译」下载或导入，模型约 610 MB，建议预留 1 GB 磁盘空间。模型按需加载，空闲一分钟后释放内存；可在设置中查看状态、重新导入或手动释放。短句语言识别和译文可能有误，请自行核对。

下载不可用时，可导入包含 `Xenova/m2m100_418M` 子目录的 `translation-models` 文件夹。

## 数据与隐私

- 工作数据默认保存在本机，可选择数据目录，支持导出和恢复备份；无需注册账户。
- 工作备份包含待办、重复规则、笔记及图片、报告草稿与历史、模板、链接、片段、启动器和界面设置；不包含剪贴板历史、录音、密码或 API Key。
- API Key 和本机密钥使用操作系统安全存储加密。更换电脑后，API 服务需重新配置。
- 剪贴板历史需要主动开启采集，可暂停或忽略应用；受支持的敏感剪贴板标记会被跳过。
- 本地翻译无需上传文字；提示词优化、AI 报告和转写会将对应文本或音频发送给用户选择的服务。AI 报告不发送图片或其他笔记。
- 目前不提供云同步。备份含工作文字与图片，请按自己的工作资料保管。

## 本地开发

技术栈为 Electron、原生 JavaScript、HTML / CSS，使用 electron-builder 构建 Windows NSIS 安装程序，无前端框架和前端编译步骤。

需要 Node.js 22.12 或更高版本，Windows 构建环境。

```bash
# 安装依赖
npm install

# 启动开发版本
npm start

# 运行单元和桌面交互测试
npm test

# 构建 Windows x64 安装包
npm run build
```

安装包输出到 `dist.noindex/`。开发、测试和打包前，会使用 Windows 自带的 .NET Framework C# 编译器构建剪贴板事件监听助手，源码位于 `native/ClipboardObserver.cs`；生成文件不提交仓库。

桌面交互测试需要可用的交互式桌面和 GPU 合成，测试期间应避免同时操作鼠标；锁屏或受限会话可能影响结果。

| 目录 / 文件 | 用途 |
| --- | --- |
| `main.js`、`main-services.js` | 窗口、系统集成和本地服务。 |
| `preload.js` | 主进程与界面的 IPC 桥接。 |
| `renderer/` | 工作台界面、主题和功能模块。 |
| `ai-*.cjs`、`report-service.cjs` | AI 服务配置、模型调用和报告生成。 |
| `todo-*.cjs` | 提醒调度和图片附件。 |
| `native/` | Windows 剪贴板事件监听助手源码。 |
| `scripts/`、`tests/` | 构建、通知脚本与自动化测试。 |
