# Slate

从屏幕顶部下拉即用的本地桌面工作台。

待办、速记、链接、录音与应用启动，都收在一块随用随走的面板里。

[功能](#功能) · [安装](#安装) · [使用方式](#使用方式) · [本地开发](#本地开发) · [路线图](#路线图)

</div>

> [!NOTE]
> Slate 当前仅支持 Windows x64。

## 为什么做 Slate

常驻侧边栏会持续占用屏幕空间，普通桌面应用又需要经过查找和打开窗口。Slate 把常用的小工具放进屏幕顶部的隐藏面板：平时移出屏幕，需要时通过下拉手势或快捷键唤出，完成操作后自动收起。

顶部手势会判断鼠标按键状态，拖动窗口时不会触发面板。需要连续编辑时，也可以固定面板，暂停自动收起。

## 功能

- **待办事项**：按今天、本周、以后安排工作，直接显示当前安排完成了多少、多少任务在等待反馈；点击添加或回车即可记录，中途新增任务同步计入当前安排。点击常显的「先做」将临时急事设为今日重点并插到最前面；计划执行日期、最终截止时间与跟进提醒分别保存
- **首页与笔记**：默认显示今日待办、随手笔记、快捷翻译和快速启动四块，快速录音常驻顶部。今日待办卡直接显示任务清单、完成数和进度条，支持随手添加、勾选完成；随手笔记卡直接输入并自动保存到笔记库，点击「新一条」继续记录。两张卡可分别显示或隐藏。笔记页也能独立新建与编辑。在完整待办页生成日/周复盘，根据真实完成时间整理草稿，保存到原有笔记库。旧完成任务没有完成时间，不会被计入新复盘的周期成果
- **链接收藏**：粘贴网址后自动获取标题和站点图标，并支持分组
- **全局搜索与文字处理**：按 `Ctrl+K` 搜索待办、笔记、链接、剪贴板、常用指令、录音转写与启动器应用。应用结果回车直接启动，剪贴板结果回车直接复制。点击「处理剪贴板」，可将最多 6000 字符的文字译成中文、存为独立笔记或转为待办；转待办会将完整原文保存在详情中，历史文字条目也可直接处理
- **任意应用快速处理文字**：复制文字后按 `Ctrl+Alt+Q`，直接呼出轻量小窗，可译为中文、存笔记或加入今日待办，无需展开 Slate。快捷键可在设置中修改或清除，也可从托盘打开。小窗按需创建、关闭即释放；仅在主动呼出或点击重新读取时读取剪贴板，不会开启剪贴板历史采集。每次最多处理 6000 字符，超长原文会完整显示并提示分段，不会截断保存
- **录音与转写**：顶部紧凑控件随时开始、暂停、继续录音，停止后自动保存；保存失败时保留本次录音，可重试或明确放弃，未保存时不会被新录音覆盖；点击旁边的箭头进入录音资料库查看音频与转写。录音保存在本机，可选接入转写服务；API Key 使用系统安全存储保存
- **快速启动**：添加常用软件，一键启动或切换到已运行的窗口
- **剪贴板历史**：入口默认显示、采集默认关闭；支持搜索、收藏、暂停、自动清理、忽略指定应用和自定义全局快捷键
- **快捷翻译**：首页小工具一键读取剪贴板并译成中文，无需进入独立页面；支持自动识别、手动选择语言、自定义全局快捷键和复制译文。首次在设置中下载或导入 M2M100 量化模型（约 610 MB），此后离线运行，原文与译文不上传、不保存历史。模型按需加载，空闲一分钟释放内存；运行时会明显增加内存占用，建议预留 1 GB 磁盘空间。短句识别可能有误，译文需自行核对。下载服务无法连接时，可导入包含 `Xenova/m2m100_418M` 子目录的 `translation-models` 文件夹。
- **删除恢复**：笔记、待办和剪贴板单条删除可撤销；录音删除提供 6 秒撤销窗口，窗口结束后才删除音频，删除失败会保留记录。未成功落盘的录音仅能在当前会话重试，系统强制终止无法保证恢复
- **备份与恢复**：导出待办、笔记、链接、指令、启动器和界面设置；隐私数据不会进入备份文件
- **任务完成提醒**：通过本地 WebSocket 接收 Codex / Claude 的任务完成通知
- **浅色与深色主题**：可手动切换，也可以跟随系统主题
- **面板固定**：连续操作时可暂停自动收起，让工作区保持展开

## 安装

### Windows

1. 在仓库的 **Releases** 页面下载最新的 `slate-*-windows-x64-setup.exe`。
2. 运行安装程序并选择安装位置。
3. 启动 Slate。应用会常驻系统托盘。

当前版本暂未提供自动更新。升级时直接运行新版安装程序覆盖安装即可，用户数据会保留。

### 从源码运行

需要 [Node.js](https://nodejs.org/) 22.12 或更高版本。

```bash
npm install
npm start
```

## 使用方式

- 将鼠标移到屏幕顶部，再向下移动约 40 px，即可拉出面板
- 按 `Ctrl+Alt+S` 可直接切换面板显示状态
- 点击面板外部或按 `Esc`，面板会自动收起
- 点击面板右上角的固定按钮，可让面板保持展开
- 按 `Ctrl+K` 打开全局搜索
- 在任意应用复制文字后，按 `Ctrl+Alt+Q` 打开文字处理小窗，选择「译为中文」「存笔记」或「转待办」；Slate 需在托盘运行。按 `Esc` 关闭小窗；在「设置 → 本机与唤出」中可修改快捷键
- 在“设置 → 剪贴板记录”中可开启采集并设置专用快捷键
- 托盘菜单可打开面板、切换固定状态、进入设置或退出应用

## 数据与隐私

- 待办、笔记、链接和设置默认保存在本机
- Slate 不要求注册账户，也不包含云同步
- 剪贴板入口默认显示，新的内容只有在用户主动开启采集后才会记录；密码管理器标记的敏感内容会被跳过
- 剪贴板可按保留期限自动清理，并可暂停或忽略指定应用
- 数据备份默认排除剪贴板历史、录音、密码和 API Key
- 录音转写只有在用户配置服务并主动使用时才会发送音频
- API Key 通过 Electron `safeStorage` 使用操作系统提供的能力加密保存

## 技术栈

- [Electron 44](https://www.electronjs.org/) + 原生 JavaScript
- HTML 与 CSS，无前端框架和前端编译步骤
- [electron-builder](https://www.electron.build/) 打包 Windows NSIS 安装程序
- Node.js 内置测试运行器与 Electron 端到端脚本

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发版本
npm start

# 运行自动化测试
npm test

# 构建 Windows x64 安装包（两个命令等效）
npm run build
npm run build:win
```

Windows 安装包生成在 `dist.noindex/` 目录。

### 项目结构

```text
main.js             Electron 主进程、窗口与手势管理
main-services.js    数据持久化、转写、链接抓取等服务
platform.js         Windows 窗口尺寸与位置策略
preload.js          主进程与渲染层之间的安全 IPC 桥接
hotzone.html        顶部透明手势感应层
renderer/           界面、主题与工作台功能
build/              应用图标和打包配置
scripts/            测试与通知辅助脚本
tests/              单元测试和 Electron 端到端测试
```

## 构建说明

- Windows 安装包建议在 Windows 环境构建
- Electron 端到端测试依赖可用的桌面和 GPU 合成；锁屏、无头或受限会话可能导致测试失败
