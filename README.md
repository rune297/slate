# Slate

从屏幕顶部下拉即用的 Windows 桌面工作台。

待办提醒、图片笔记、剪贴板、离线翻译、提示词优化与工作报告，收在一块随用随走的面板里。

## 为什么做 Slate

Slate 面向日常桌面办公：在首页看今天的事项与完成进度，随手记文字或图片，复制后快速处理内容，按任务记录整理日报、周报和月报。重复工作可以按日历自动生成待办，到点提醒；常用软件、片段、链接和录音也能快速找到。

工作数据保存在本机。日常记录与报告整理无需配置 AI；本地翻译在下载或导入模型后可离线使用。需要提示词优化、AI 报告或录音转写时，再按用途选择云端 API 或自行运行的兼容本地服务。

常驻侧边栏会持续占用屏幕空间，普通桌面应用又需要经过查找和打开窗口。Slate 把常用的小工具放进屏幕顶部的面板：平时收起为一条细小的主题色提示条，需要时通过下拉手势或快捷键唤出，完成操作后滑动收起。

顶部手势会判断鼠标按键状态，拖动窗口时不会触发面板。需要连续编辑时，也可以固定面板，暂停自动收起。

## 功能

- **待办事项**：按今天、本周、以后安排工作，直接显示当前安排完成了多少、多少任务在等待反馈；点击添加或回车即可记录，中途新增任务同步计入当前安排。点击「优先做」将临时急事排到首页今天最前面，不改变原计划和截止日期；计划执行日期、最终截止时间与跟进提醒分别保存
- **首页与笔记**：默认显示今日待办、随手笔记、提示词优化/本地翻译和快速启动四块，快速录音常驻顶部。今日待办卡直接显示任务清单、完成数和进度条，支持随手添加、勾选完成；随手笔记卡直接输入并自动保存到笔记库，点击「新一条」继续记录。两张卡可分别显示或隐藏。笔记页也能独立新建与编辑。在完整待办页生成日/周复盘，根据真实完成时间整理草稿，保存到原有笔记库。旧完成任务没有完成时间，不会被计入新复盘的周期成果
- **链接收藏**：粘贴网址后自动获取标题和站点图标，并支持分组
- **全局搜索与文字处理**：按 `Ctrl+K` 搜索待办、笔记、链接、剪贴板、常用片段、录音转写与启动器应用。应用结果回车直接启动，剪贴板结果回车直接复制。点击「处理剪贴板」，可将最多 6000 字符的文字译成中文、存为独立笔记或转为待办；转待办会将完整原文保存在详情中，历史文字条目也可直接处理
- **任意应用快速处理文字**：复制文字后按 `Ctrl+Alt+Q`，直接呼出轻量小窗，可译为中文、存笔记或加入今日待办，无需展开 Slate。快捷键可在设置中修改或清除，也可从托盘打开。小窗按需创建、关闭即释放；仅在主动呼出或点击重新读取时读取剪贴板，不会开启剪贴板历史采集。每次最多处理 6000 字符，超长原文会完整显示并提示分段，不会截断保存
- **录音与转写**：顶部紧凑控件随时开始、暂停、继续录音，停止后自动保存；保存失败时保留本次录音，可重试或明确放弃，未保存时不会被新录音覆盖；点击旁边的箭头进入录音资料库查看音频与转写。录音保存在本机，可选接入转写服务；API Key 使用系统安全存储保存
- **快速启动**：添加常用软件，一键启动或切换到已运行的窗口
- **剪贴板历史**：入口默认显示、采集默认关闭；支持搜索、收藏、暂停、自动清理、忽略指定应用和自定义全局快捷键
- **快捷翻译**：首页小工具一键读取剪贴板并译成中文，无需进入独立页面；支持自动识别、手动选择语言、自定义全局快捷键和复制译文。首次在设置中下载或导入 M2M100 量化模型（约 610 MB），此后离线运行，原文与译文不上传、不保存历史。模型按需加载，空闲一分钟释放内存；运行时会明显增加内存占用，建议预留 1 GB 磁盘空间。短句识别可能有误，译文需自行核对。下载服务无法连接时，可导入包含 `Xenova/m2m100_418M` 子目录的 `translation-models` 文件夹。
- **删除恢复**：笔记、待办和剪贴板单条删除可撤销；录音删除提供 6 秒撤销窗口，窗口结束后才删除音频，删除失败会保留记录。未成功落盘的录音仅能在当前会话重试，系统强制终止无法保证恢复
- **备份与恢复**：导出待办及其图片附件、重复规则、笔记及其图片、工作报告草稿、历史与模板、链接、常用片段、启动器和界面设置；不包含剪贴板历史、录音、密码与 API Key
- **任务完成提醒**：通过本地 WebSocket 接收 Codex / Claude 的任务完成通知
- **浅色与深色主题**：可手动切换，也可以跟随系统主题
- **面板固定**：连续操作时可暂停自动收起，让工作区保持展开

## 1.5 版本新增

本次新增待办提醒、重复事项、图片附件、工作报告、首页提示词优化与复制反馈，并整合 AI 服务配置、常用片段和手势交互。首页仍默认保留「今日待办、随手笔记、提示词优化/本地翻译、快速启动」四张卡片，录音入口仍在顶部。

| 功能 | 入口与使用方式 |
| --- | --- |
| 日期与到点提醒 | 设置截止时间后，到点自动提醒；默认每天 18:00 汇总未完成事项，可在「设置 → 待办提醒」关闭或改时间。紧凑的右下角提醒窗可标记「已经完成」、通过「调整任务」延期或打开原待办修改，也可选择「知道了」。已有的自定义提醒配置继续保留。 |
| 手动下拉与收起 | 按住顶部细条向下拉可展开，展开后按住底部细条向上推可收回。面板跟随鼠标，越过阈值松手后切换，否则返回原状态；保留轻点、键盘和点击外部收起。 |
| 顶部任务提示条 | 收起后保留细小提示条；出现逾期待办时变为温和的暖色，重要逾期事项进一步突出。提示条用于提示任务状态，不会自动标记任务完成。 |
| 待办图片 | 展开任务详情后点击「添加图片」，也可在该任务详情内粘贴或拖入图片。每条最多 8 张，单张不超过 10 MB；点击缩略图可放大，并可切换原始尺寸。剪贴板图片也可转为带图待办。 |
| 重复事项 | 在完整待办页点击「重复事项」，或从任务详情的更多选项选择「设为重复事项」。填写事项和重复方式即可保存，默认今天 18:00；每周可选星期，每月可选日期。结束日期、分类和说明等放在「更多选项」，已有规则可直接暂停、恢复。 |
| 日报、周报与月报 | 在待办页点击「工作报告」，选择周期与日期，使用「AI 生成草稿」或无需 API 的「仅整理任务」。结果先进入可编辑草稿，点击「保存到历史」才归档；历史支持搜索、删除和撤销删除。 |

### 提醒与重复事项的运行规则

- Slate 需要保持托盘运行；关闭主面板不影响提醒，退出程序或电脑关机时无法提醒。电脑休眠时不会弹窗，唤醒后会重新检查并合并补发符合条件的提醒。
- 提醒全部使用本机时间。「知道了」只确认本次提醒，不会完成任务；任务仍未完成时，下次汇总可以再次提醒。
- 重复规则到期后生成独立的待办，与普通任务一样可以完成、改期、补充说明和图片。设置截止时间后，再配合开启「待办提醒」，即可到点提醒。
- 程序关闭期间不会逐次生成任务；重新运行时，每条规则只补最近一次符合条件的任务，避免堆积。每月设置 29、30 或 31 日，而当月没有该日时，在月末生成。
- 暂停或删除规则不删除已经生成的待办。恢复规则从恢复当天起继续，不补齐暂停期间的全部任务。

### 工作报告与 API 配置

1. 打开「设置 → AI 配置 → 管理 AI 服务」，选择服务商模板，填写 Key，读取或填写模型名称后保存；再到「功能分配」选择提示词优化、工作报告、智能整理或录音转写使用的服务和模型。同一个服务可复用，各功能也能选择不同服务或模型。
2. 打开「待办 → 工作报告」，选择日报、周报或月报及所在日期；周报按周一至周日，月报按自然月。
3. 点击「AI 生成草稿」先检查配置，成功后才把结果放入当前草稿。未配置会引导配置；失败、取消不创建历史，也不替换原稿。选择「仅整理任务」可直接把本机待办整理成文字，无需 API，同样不会自动新增历史。
4. 日报、周报、月报使用不同的纯文本模板，无 `##` 等 Markdown 标记；月报包含问题与所需协助，只引用待办里记录的卡点。需要定制时，在「设置 → AI 配置 → 自动报告提示词」选择周期，修改排版模板；各周期独立保存，无需 API 也能用于本地整理。AI 默认采用内置 Skill，也可选择自定义写作要求或导入 `.md` / `.txt`（包括 `SKILL.md`），不执行其中的命令。
5. 草稿可直接编辑、复制，并自动保留在本机；确认后点击「保存到历史」归档。已存报告的编辑更新原条目，不重复创建。生成期间若有人工编辑，AI 结果会留待用户明确使用或复制。历史支持搜索、删除及撤销删除。

设置采用左侧分类与搜索、右侧当前设置。可搜索设置名称和说明，跳到相应类别；快捷键、外观、首页功能、剪贴板、提醒、翻译、AI 和数据管理分别展示。

报告只在主动生成时发送所选范围的待办文字，不发送图片或其他笔记。生成失败、取消或超时保留原稿；内容太多时会说明未发送的详情，原待办不会被截断。缺少真实完成时间的旧任务不会被虚构为本期成果，未记录的顺延原因也不会自动补写。

工作报告需要自行选择和配置服务商。第三方 API 是否收费及用量计费以服务商规则为准，Slate 不附送 API 额度。密钥由系统安全存储加密，数据备份中不包含密钥；在其他电脑恢复数据后需重新配置。报告草稿、历史和模板则随工作区与数据备份保留。

### 更多 1.5 功能与交互改进

- **首页提示词优化**：原翻译卡支持“提示词优化 / 本地翻译”切换，默认显示优化器。读取剪贴板或输入提示词后，一键改写、编辑结果、复制全文或存为常用片段；支持可选补充要求和本机草稿。只在主动点击时调用所选模型，失败、取消和人工编辑期间的旧响应不会覆盖已有文字。
- **统一 AI 服务**：提供 OpenAI、Claude、Gemini、DeepSeek、Kimi、智谱/Z.AI、火山方舟、百炼、硅基流动、OpenRouter、MiniMax、Groq、xAI、Ollama、LM Studio 和自定义兼容接口等模板。Claude 接入原生 Messages，其余文字服务通过 OpenAI 兼容接口；支持获取模型列表和连接测试。不提供模型列表的接口可手动填写，实际权限与计费以服务商为准，订阅套餐的地址可能不同。
- **本地生成模型**：Ollama / LM Studio 需由用户安装并启动，默认填好本地地址，通常无需 Key；Slate 不自动安装大模型。现有 M2M100 只用于翻译。录音转写必须选择支持音频的服务和模型，普通聊天模型不能当作音频接口。

- **常用片段**：顶部片段图标可打开多行内容列表，搜索筛选，点击复制全文；新增与铅笔编辑使用独立多行编辑区，支持 Ctrl+Enter 保存、长文展开和 16,000 字。保存命令也只复制，不执行，原有片段保留。
- **桌面复制反馈**：复制文字、图片或文件后在左下角短暂提示；连续快速复制会显示“去粘贴吧”和次数。无需打开工作台，不开启历史采集，不抢焦点，可在「设置 → 剪贴板」关闭。受保护的剪贴板内容和保密箱密码复制不显示预览。
- **整板手势**：顶部下拉、整个底部上推时，整块工作台一起移动；越过阈值松手后展开或收起，短拉回弹，边界带阻尼。

- **分类**：新用户只有「全部分类」「未分组」，无需先建立分类就能记任务。点击任务分类可搜索直选；在管理分类中新增、排序、重命名或删除，自定义分类删除后任务移到未分组。「优先做」把任务置顶到首页今天，不改变原计划与截止日期。
- **图片笔记**：首页随手笔记、笔记库均可选择、粘贴或拖入图片，也可只保存图片；每篇最多 8 张、单张 10 MB，支持放大、原图、移除与撤销，笔记图片随数据备份保留。
- **模型管理**：在「设置 → 本地翻译」查看安装、加载和运行状态，可下载、重新导入、刷新或释放模型内存。
- **API 模板与测试**：「设置 → AI 配置」统一管理服务，再分配到各个功能。支持测试当前填写的服务和模型，密钥留空可保留同一地址、同一厂商的已保存 Key；测试不会借用其他服务的 Key。测试会调用接口，可能产生少量费用，不会发送工作内容或自动保存配置。
- **录音服务商**：百炼支持实时转写；OpenAI 或兼容的 `/audio/transcriptions` 接口支持停止录音后转写，单次最多 10 分钟。先保存本地音频，再等待云端结果，失败仍保留音频。聊天模型不能代替音频模型。
- **批量历史管理**：报告历史支持勾选、全选搜索结果、图标删除、清空全部历史与撤销；清空需要确认，当前草稿保留。
- **整个底部可上推**：展开后从底部任意位置按住向上拖动，超过阈值后松手收起，短拉或取消则回到展开状态。

## 安装

### Windows

1. 下载 [slate-1.5.0-windows-x64-setup.exe](https://github.com/rune297/slate/releases/download/v1.5.0/slate-1.5.0-windows-x64-setup.exe)，或在仓库的 [Releases](https://github.com/rune297/slate/releases) 页面查看历史版本。
2. 运行安装程序并选择安装位置。
3. 启动 Slate。应用会常驻系统托盘。

当前版本暂未提供自动更新。升级时直接运行新版安装程序覆盖安装即可，用户数据会保留。

### 从源码运行

需要 [Node.js](https://nodejs.org/) 22.12 或更高版本。

```bash
npm install
npm start
```

## 使用方式

- 按住屏幕顶部的细条向下拖动，越过阈值松手展开；未达到阈值松手则自动收回
- 按 `Ctrl+Alt+S` 可直接切换面板显示状态
- 点击面板外部或按 `Esc`，面板会自动收起
- 点击面板右上角的固定按钮，可让面板保持展开
- 收起后的顶部提示条会提示逾期待办；默认到点提醒、每天 18:00 汇总，可在「设置 → 待办提醒」关闭或改时间
- 在完整待办页进入「重复事项」设置固定安排，进入「工作报告」整理日报、周报或月报
- 按 `Ctrl+K` 打开全局搜索
- 在任意应用复制文字后，按 `Ctrl+Alt+Q` 打开文字处理小窗，选择「译为中文」「存笔记」或「转待办」；Slate 需在托盘运行。按 `Esc` 关闭小窗；在「设置 → 本机与唤出」中可修改快捷键
- 在“设置 → 剪贴板记录”中可开启采集并设置专用快捷键
- 托盘菜单可打开面板、切换固定状态、进入设置或退出应用

## 数据与隐私

- 待办、笔记、链接和设置默认保存在本机
- Slate 不要求注册账户，也不包含云同步
- 剪贴板入口默认显示，新的内容只有在用户主动开启采集后才会记录；密码管理器标记的敏感内容会被跳过
- 剪贴板可按保留期限自动清理，并可暂停或忽略指定应用
- 数据备份默认排除剪贴板历史、录音、密码和 API Key
- 待办图片、重复规则、工作报告历史与模板包含在数据备份中；备份文件含有工作文本和图片，应按自己的工作资料保管
- 录音转写只有在用户配置服务并主动使用时才会发送音频
- 工作报告只有在主动点击 AI 生成时才会向单独配置的服务发送相关待办文字；图片和其他笔记不随请求发送，本地整理草稿无需联网
- API Key 通过 Electron `safeStorage` 使用操作系统提供的能力加密保存

## 技术栈

- [Electron 44](https://www.electronjs.org/) + 原生 JavaScript
- HTML 与 CSS，无前端框架和前端编译步骤
- [electron-builder](https://www.electron.build/) 打包 Windows NSIS 安装程序
- Node.js 内置测试运行器与 Electron 端到端脚本

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发版本
npm start

# 运行自动化测试
npm test

# 构建 Windows x64 安装包（两个命令等效）
npm run build
npm run build:win
```

Windows 安装包生成在 `dist.noindex/` 目录。

### 项目结构

```text
main.js             Electron 主进程、窗口与手势管理
main-services.js    数据持久化、转写、链接抓取等服务
todo-reminders.cjs  待办提醒调度与右下角提醒窗口
todo-attachments.cjs 待办图片、本地读取与备份导入导出
report-service.cjs  独立的报告 API、加密配置与生成请求
platform.js         Windows 窗口尺寸与位置策略
preload.js          主进程与渲染层之间的安全 IPC 桥接
hotzone.html        顶部透明手势感应层
renderer/           界面、主题与工作台功能
build/              应用图标和打包配置
scripts/            测试与通知辅助脚本
tests/              单元测试和 Electron 端到端测试
```

## 构建说明

- Windows 安装包建议在 Windows 环境构建
- 开发、测试、打包前会自动使用 Windows 自带 .NET Framework C# 编译器生成剪贴板事件监听助手；源码在 `native/ClipboardObserver.cs`，生成文件不提交仓库，不需要安装 Python 或额外服务。
- Electron 端到端测试依赖可用的桌面和 GPU 合成；锁屏、无头或受限会话可能导致测试失败
